## Short
I made a free browser-based preflight for Japanese game UI text. It runs locally and checks common mechanical risks such as placeholder drift, kinsoku line starts/ends, half-width katakana, ideographic spaces, punctuation mixing, and approximate layout pressure. It also includes a 40-string EN↔JA sample.

Tool: https://camembert1001.github.io/boyaki-public/yn0-jp-ui-preflight/

## GitHub / developer audience
JP UI Preflight is a small offline checker for EN/JA locale maps. It is intentionally not a translation-quality scorer: it focuses on deterministic implementation and typography risks that can be caught before in-context LQA. The free tool and 40-string sample are MIT-licensed.

Tool: https://camembert1001.github.io/boyaki-public/yn0-jp-ui-preflight/
