BOYAKI Maker Space

解決を、Caseとして残す場所。

BOYAKIスレッドで「解く価値がある」と見えた問題を、Maker Space内のSolution RoomでVoiceとMakerが一緒に詰めます。ここで積み上がるやり取りがSolution Logになり、後のContribution Historyの根拠になります。

Thread → Room探索段階の会話から、解決を具体化する段階へ切り替える。
Voice + Maker困りごとの文脈と、解決を作る力を同じCaseに集める。
Solution Log試したこと、失敗、修正、検証を時系列で残す。
Case → History完成したCaseをMaker / Voice Contribution Historyの根拠に使う。

このステージング版では既存のSolution CandidateをSolution Roomとして扱い、既存の公開活動ログをSolution Logとして継続利用します。BOYAKIスレッドからのRoom新規作成・招待フローは次の実装対象です。

Solution Rooms

Solution Room

1 Room = 1 Solution Case。中での作業履歴がそのままCaseの証拠になります。

Join Solution Room

Solution Roomに参加

参加情報はCaseに残ります。Maker / Voiceのどちらとして関わったかを選び、必要なら一言だけ役割を補足してください。

Solution Log

Solution Logを追加

後からCaseを読んだ人が「どう解決に近づいたか」を追えるように、行動・発見・失敗・検証を残します。

Case identity

この活動を誰の履歴として残すか

BOYAKI Accountでログイン済みならAccount IDで署名します。未ログイン時だけ、このブラウザの旧仮IDをフォールバックとして使います。Contribution Historyへ接続する本流はAccount IDです。
